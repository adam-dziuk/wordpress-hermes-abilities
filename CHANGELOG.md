# Changelog

All notable changes to this project are documented in this file.

## [1.2.0] - GitHub release prep

- Added translation loading (`load_plugin_textdomain`) and a `languages/` directory with a `.pot` file.
- Added `License URI`, `Text Domain`, and `Domain Path` headers.
- Added a dashboard notice for activation without Abilities API support (WordPress < 6.9).
- Added README, LICENSE, CHANGELOG, and `.gitignore`.
- Translated all code comments, ability labels/descriptions, and error messages to English.
